# YouTube-Music-Player
An unofficial light-weight desktop Music Player for YouTube Music, without all the bloat of the Official YouTube Music Website and Application, Ad-Free/No Sign Ups, Created for personal use and is perfect whilst gaming.

This project is and always will be open-source.

# Disclaimer/Important Infomation
#### __*AI was used to AID development of this application, It was not entirely written/designed by AI but this was my first time ever making an application so AI assisted me (I support AI programming if its used as a tool to enhaned human programming and not used to vibe code entire projects)*__
* This project is a personally passion project that is NOT affilated with Google, YouTube or YouTube Music and is not supported by them in ANY way.
* This project will never ask for money, Google Login Information, or other personal information.
* This project never collects any data, it only reads and writes files into and from %appdata%/OakMusic, for Playlist, settings. however everything is saved to a json file so you can read and edit everything.
